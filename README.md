# My Social Networks API  David MESSAGE

## Démarrer

```bash
npm install
npm start
```

API : `http://localhost:3000`

Importer `My Social Networks API.postman_collection.json` dans Postman. Chaque ressource contient les requêtes `GET` liste, `POST`, `PUT` et `DELETE`. Le `GET` par id est indiqué dans la description du dossier.

## Ressources

`users`, `events`, `groups`, `discussions`, `messages`, `comments`, `albums`, `photos`, `polls`, `questions`, `pollResponses`, `ticketTypes`, `tickets`, `shoppingItems`.
